- 分页仅影响显示，不改变完整队列读取、通知判断和去重。

C# / .NET 10 / WPF，Windows x64 免安装托盘应用。只读取审核队列，审核操作在浏览器完成。

## 使用

1. 将发布目录放到当前用户有写入权限的位置，运行 `openEulerReviewMonitor.exe`。不需要安装 .NET。
2. 在“设置”的“论坛认证”区域选择 Cookie 或 API Key。Cookie 填浏览器请求的完整 Cookie 值（不是网页 URL、整段请求或 Set-Cookie 响应头）。API Key 填密钥，并按论坛的密钥配置填写 API 用户名。
3. 点击“验证认证”。按钮和提示区会显示验证中，完成后只在认证区域保留绿／红色结果提示，不弹出对话框；失败会尽可能区分 HTTP 401/403、重定向、HTML 页面、网络异常等原因。验证最长 60 秒，独立于监控和机器人配置，不保存设置、不推送消息。点击“保存认证”后可启动监控；启动会立即检查，以后默认每 15 分钟检查一次。
4. Windows 通知始终开启。通过下拉框选择 Windows、企业微信、钉钉或飞书，显示对应配置；机器人可独立启用并填写 Webhook，钉钉、飞书支持签名密钥。切换下拉框不关闭其他已启用渠道。
5. 各渠道配置下方的测试按钮只测试当前渠道，不要求论坛凭据、不保存设置，也不会自动启用该渠道。测试结果仅在页内显示；Windows 测试会发送实际系统通知。启用关键词限制的机器人请允许 `openEuler`。
6. 认证和推送配置需先停止监控再修改。检查间隔和重复提醒位于“设置”的“监控选项”区域。有效时间输入立即自动保存并生效；无效输入不会覆盖已保存值，离开输入框后恢复。
7. 默认点击 X 隐藏到托盘，双击托盘图标恢复。可在左下角取消该选项改为直接退出，修改会立即自动保存；托盘菜单始终提供明确的“退出”。
8. 点击“运行日志”页签即可查看日志，顶部不再提供重复的查看日志按钮。支持复制、导出全部磁盘日志和关闭自动滚动。
9. 底部状态在同一行按监控状态、检查结果、待审核数量、上次检查、上次成功、下次检查排列。

## 监控规则

- 读取 `review.json?status=pending` 的完整分页；不限审核类型，包含插件新增的类型。
- 首次发现的待处理项按审核项 ID 汇总通知；审核数量不变但 ID 改变也会通知。
- 各通知渠道独立去重；重新启动不重复推送已通知项。未成功的渠道下次检查补发。网络超时／连接失败会进行最多三次发送尝试（网络响应丢失时可能重复送达）。
- 去重记录只保留当前待处理 ID；离开队列后再次进入的同一 ID 会重新提醒。
- 默认不重复提醒未处理项；可配置重复提醒间隔，0 为关闭。更换 Webhook 后该渠道会提醒当前待处理项。
- 检查失败保留上次成功列表，状态显示失败。认证失效会额外提交一次 Windows 提醒，恢复成功后重置该提醒。
- 手动、定时、验证、测试操作互斥。下一次检查从本次检查和推送完成后计时。停止会取消正在执行的请求。
- 同一台电脑使用固定全局互斥锁限制一个实例；再次启动尝试唤起原窗口。不同 Windows 用户／会话的权限边界可能使第二个实例只能退出而无法唤起。
- 登录 Windows 后可托盘运行；电脑休眠、关机、用户注销期间不监控，休眠恢复后补查。不包含开机自启或 Windows 服务。
- Windows 通知提交成功不代表用户已看到；通知显示受 Windows 通知、勿扰和远程会话设置影响。

## 便携与数据

EXE 包含 .NET 运行时，运行时可能解压内部组件到系统临时目录。首次运行会在 EXE 旁创建 `data`：

- `settings.dat`：整份设置使用 Windows DPAPI 当前用户加密，包含凭据、Webhook 等。
- `state-*.json`：各站点的通知去重 ID 和提醒时间，不包含 Cookie 或帖子正文。
- `logs/`：滚动日志，单文件约 5 MB，保留最近 30 天；日志窗口显示本次运行最近 2000 条，可导出磁盘上的全部保留日志。

退出后可移动整个目录。同一 Windows 用户在同一电脑内移动通常不需要重新配置；换电脑／用户后需重新填写配置。只移动 EXE 会使用新建的默认配置和去重记录。凭据不提供明文导出，不要放到 Program Files 等不可写位置。

## 编译与测试

安装 .NET 10 SDK 后，在项目目录执行：

```powershell
dotnet build -c Release
dotnet run --project Tests/Tests.csproj -c Release
./publish.ps1
```

发布产物在 `dist/win-x64`。当前实现不使用第三方 NuGet 包。源码中的核心测试使用模拟 HTTP 响应，不访问真实论坛、不发送群消息。

真实 Cookie/API Key、论坛实际字段以及三个群机器人的端到端收发需要在用户环境验证。首次交付尚未做真实账号和群机器人联调。
